# ScreenRec

Утилита записи экрана в **MP4** для Wayland-композитора **niri**.
Захват области — через `slurp` + `grim`, кодирование — `ffmpeg` (H.264, нативное разрешение, CRF 18).

## Файлы
- `~/.local/share/screenrec/screenrec` — единый исполняемый скрипт (все подкоманды).
- `~/.local/share/screenrec/README.md` — эта документация.
- Состояние и готовые видео:
  - `/run/user/<uid>/screenrec/` — временные файлы и флаг активности (tmpfs, исчезает после перезагрузки).
  - `~/Downloads/screenrec-<timestamp>.mp4` — готовые записи (путь настраивается).

## Подкоманды
| Команда | Назначение |
|---------|------------|
| `screenrec start`  | Выбрать область и начать запись. |
| `screenrec stop`   | Остановить запись. |
| `screenrec status` | Вывод JSON для виджета бара (иконка + текст). |
| `screenrec capture`| Внутренняя: фоновый захват и сборка MP4. |

## Горячие клавиши (niri, `~/.config/niri/config.kdl`)
- **Mod+Shift+G** — начать запись. Откроется выбор области:
  - клик по монитору → запись всего этого монитора;
  - перетащить мышью → своя область;
  - Esc → отмена.
- **Mod+Shift+X** — остановить запись.

Также остановить можно кликом по индикатору в баре.

## Индикатор в баре (noctalia-shell)
Виджет `CustomButton` в правой секции бара (слева от колокольчика уведомлений):
- **Простой:** квадратный стоп-значок в цвете темы, надпись скрыта.
- **Запись:** пульсирующий красный кружок + красная надпись `REC m:ss` с таймером.
- Клик по виджету = стоп.

Настраивается в `~/.config/noctalia/settings.json` (блок `bar.widgets.right`,
виджет с `textCommand`, указывающим на `screenrec status`).

## Настройка
Значения хранятся в `~/.config/screenrec.conf` и читаются при старте записи.

Их можно задать двумя способами:

1. **Через панель плагина** (рекомендуется): правый клик по виджету в баре →
   «Settings» → выбор папки сохранения и FPS. Изменения сразу пишутся в конфиг.
2. **Переменными окружения** при запуске:

| Переменная окружения | Значение по умолчанию | Описание |
|----------------------|-----------------------|----------|
| `SCREENREC_OUT_DIR`  | `~/Downloads`         | Куда сохранять видео. |
| `SCREENREC_FPS`      | `15`                  | Частота кадров. |
| `SCREENREC_FORMAT`   | `mp4`                 | Формат: `mp4` (H.264), `webm` (VP9), `mkv` (H.264), `gif`. |

Пример: `SCREENREC_OUT_DIR=$HOME/Видео SCREENREC_FPS=30 screenrec start`

## Зависимости
`grim`, `slurp`, `ffmpeg` (с поддержкой libx264), `notify-send`.
